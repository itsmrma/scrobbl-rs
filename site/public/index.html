Numbers you can trust.

Statistics are only useful if you know what they count. These are the rules the archive follows.

Imported plays count from 30 seconds

Imported plays of 30 seconds or longer count in statistics. Shorter records stay searchable in your history.

Unknown stays unknown

A missing listening time is never shown as zero, and an estimated time is labelled as an estimate.

Possible duplicates wait for you

Uncertain matches stay separate until a review. Removed listens go to a recoverable trash, and a decision can be undone.

Install in three steps.

  1. 1

    Start the container

    Run the prebuilt image with Docker Compose, or run from source on your own machine.

  2. 2

    Create the owner account

    Open the configured address and choose an owner password of at least 12 characters.

  3. 3

    Connect Spotify and import

    Connect Spotify in Settings to collect new listens, and import your Extended Streaming History or ListenBrainz export.

# Get the Compose file
curl -fsSLO https://raw.githubusercontent.com/itsmrma/scrobbl-rs/main/compose.yaml
# A new, dedicated data directory on a local disk
sudo install -d -o 10001 -g 10001 -m 0700 /srv/scrobbl/data
# Pin the image to a commit from a successful Docker run, not a floating tag
export SCROBBL_IMAGE=ghcr.io/itsmrma/scrobbl-rs:sha-FULL_COMMIT
export SCROBBL_EXTERNAL_ORIGIN=http://192.0.2.10:3210
export SCROBBL_HOST_IP=192.0.2.10
export SCROBBL_DATA_PATH=/srv/scrobbl/data
# Start it
docker compose pull
docker compose up -d

Replace the documentation addresses with yours and pin SCROBBL_IMAGE to a commit or digest (use :vulkan or -vulkan tags for Linux/Windows GPU passthrough, or native Metal on macOS). See the full Docker guide for UID/GID, HTTPS and Spotify.

# Needs a stable Rust toolchain
./scripts/run-local.sh

Then open http://127.0.0.1:3210 and create the owner account. On macOS Apple Silicon, build with --features metal or download scrobbl-rs-macos-arm64-metal.tar.gz from Releases for native Metal acceleration. Keep the process running to collect listens.
