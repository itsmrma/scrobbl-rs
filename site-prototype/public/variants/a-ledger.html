Numbers you can trust.

An archive is only useful if it doesn't guess. scrobbl.rs keeps the evidence, separates it from your corrections, and says when it doesn't know.

Plays count at 30 seconds

Shorter records stay searchable in history but don't inflate your statistics.

Unknown stays unknown

A missing duration is never shown as zero, and estimated time is labelled as an estimate.

Uncertain matches stay separate

Possible duplicates wait for your review. Decisions go to a recoverable trash and can be undone.

Up in a few minutes.

Runs on your own machine or a private server, reached over your LAN, VPN or HTTPS.

  1. Start the container

    A published image for linux/amd64, or build from source with Rust.

  2. Create the owner account

    One archive, one owner. Sessions and secrets live in a separate database.

  3. Connect Spotify and import

    Use your own Spotify app, then add your extended history export.

# compose.yaml lives in the repository
export SCROBBL_IMAGE=ghcr.io/itsmrma/scrobbl-rs:main
export SCROBBL_EXTERNAL_ORIGIN=https://music.example.lan
export SCROBBL_HOST_IP=192.168.1.20
export SCROBBL_DATA_PATH=/srv/scrobbl/data
docker compose up -d
git clone https://github.com/itsmrma/scrobbl-rs
cd scrobbl-rs
./scripts/run-local.sh
# open http://127.0.0.1:3210
