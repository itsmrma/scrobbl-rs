## Agent skills

### Project context

Before planning or changing behavior, read the
[development map](https://github.com/itsmrma/scrobbl-rs/issues/1)
for requirements, confirmed choices, prototype status and open decisions.

### Issue tracker

Track issues and specs in GitHub Issues for `itsmrma/scrobbl-rs`.
For ticket operations, read `docs/agents/issue-tracker.md`.

### Pull requests

Create PRs ready for review, without `--draft`. Before calling a PR ready to
merge, verify that required checks pass and GitHub reports no merge blockers.

Link every PR to its ticket through GitHub's native Development relationship.
For a PR resolving the ticket, include `Closes #<number>` in the PR body.
Before handoff, verify the native link appears on the ticket.

### Triage labels

Use the five default triage labels.
Before triaging, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`.
Before exploring the codebase, read `docs/agents/domain.md`.
